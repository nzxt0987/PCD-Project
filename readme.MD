# Eksplorasi Ruang Warna & Kanal Citra

Project Pengolahan Citra Digital - Pertemuan 2.

Aplikasi GUI Python untuk membaca citra digital dan melakukan
eksplorasi berbagai ruang warna serta isolasi kanal warna.

## Tujuan

Aplikasi ini dibuat untuk:
- Membaca citra JPG/PNG.
- Menampilkan citra asli.
- Melakukan konversi citra ke Grayscale.
- Melakukan konversi citra ke HSV.
- Melakukan konversi citra ke YCrCb.
- Mengisolasi Channel Red.
- Mengisolasi Channel Green.
- Mengisolasi Channel Blue.
- Menambahkan ruang warna tambahan CIE-LAB.
- Menampilkan hasil transformasi pada GUI.

## Teknologi

- Python 3.11+
- Tkinter
- OpenCV
- NumPy
- Pillow
